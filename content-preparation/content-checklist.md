# Phase-0-Checkliste

## Identität und globale Angaben

- [ ] öffentlicher Modelname festgelegt
- [ ] Schreibweise und Groß-/Kleinschreibung bestätigt
- [ ] primäre Sprache festgelegt
- [ ] gewünschte Domain und Alternativen notiert
- [ ] öffentlicher Kontakt festgelegt
- [ ] Instagram-Handle und URL ergänzt
- [ ] `[2026]`-Statement als Entwurf vorhanden

## Profil

- [ ] kurze Biografie mit 2–4 Sätzen vorhanden
- [ ] Base / Stadt ergänzt
- [ ] gewünschte Modelangaben ergänzt
- [ ] Agentur oder Repräsentation ergänzt, falls vorhanden
- [ ] Profilportrait ausgewählt
- [ ] Alt-Text für das Profilportrait geschrieben

## Shooting 1

- [ ] Metadaten ausgefüllt
- [ ] Bilder als Web-Exporte vorhanden

- [ ] genau ein INDEX-Cover ausgewählt
- [ ] Archiv-Sichtbarkeit festgelegt
- [ ] Alt-Texte ergänzt
- [ ] Credits geprüft

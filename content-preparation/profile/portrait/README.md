# Profilportrait hier ablegen

Lege hier ein starkes Portrait für die PROFILE-Seite ab und trage seinen exakten
Dateinamen sowie den Alt-Text in `../profile.md` ein.

Empfehlung:

- hochauflösender Web-Export
- sRGB
- ungefähr 3000–4000 px an der langen Kante
- JPEG oder WebP bevorzugt
- keine RAW-Datei
- Dateiname beispielsweise `model-name-profile.jpg`

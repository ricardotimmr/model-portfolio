# Shooting-Bilder hier ablegen

Lege die Web-Exporte dieses Shootings in diesem Ordner ab.

- JPEG oder WebP bevorzugt; PNG und AVIF sind ebenfalls möglich
- sRGB, lange Kante ungefähr 3000–4000 px
- keine RAW-Dateien oder unnötig großen Kameraoriginale
- stabile Namen ohne Leerzeichen, zum Beispiel `coastal-light-01.jpg`
- keine Kopie des Covers anlegen; markiere das vorhandene Bild in `../photos.csv`
  mit `cover=true`
- für jedes Bild genau eine Zeile in `../photos.csv` anlegen

Die beiden Beispielzeilen in `photos.csv` anschließend ersetzen.
